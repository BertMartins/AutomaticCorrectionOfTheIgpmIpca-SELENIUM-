# Correção Automática IGP-M / IPCA

Automação em Python + Selenium que corrige valores pelo IGP-M e IPCA usando a Calculadora do Cidadão, gerando os resultados sem trabalho manual.

## 🛠️ Tecnologias

- Python
- Selenium
- PyInstaller

## 🚀 Como executar

```bash
git clone https://github.com/BertMartins/AutomaticCorrectionOfTheIgpmIpca-SELENIUM-.git
cd AutomaticCorrectionOfTheIgpmIpca-SELENIUM-
```

Instale as dependências (`pip install selenium`) e execute o script Python principal.
